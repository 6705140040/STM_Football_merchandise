# 📜 Project Charter – STM Internet Cafe Management System

## 1. Purpose
The purpose of this project is to develop a management system for STM Internet Café.  
It aims to streamline customer session tracking, billing, and inventory management while ensuring secure and efficient operations.

---

## 2. Objectives
- Provide a secure login system for staff and administrators.  
- Track customer computer usage sessions automatically.  
- Generate accurate billing based on session duration and services used.  
- Manage café inventory (snacks, drinks, accessories).  
- Deliver performance reports for business insights.  

---

## 3. Scope
**In Scope:**  
- User authentication and role management.  
- Session tracking and billing automation.  
- Inventory management module.  
- Reporting and analytics dashboard.  

**Out of Scope:**  
- Integration with external payment gateways (future consideration).  
- Mobile app version (future enhancement).  

---
